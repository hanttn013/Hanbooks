# Hanbooks

Hanbooks is an offline EPUB reader for personal libraries. The main app is a React + Vite web app wrapped for Android with Capacitor.

The current product name inside the source is **Aurelia Books** (`com.aurelia.books`). The app is designed for lightweight reading, fast reopening, offline storage, and EPUB libraries imported by the user.

## Main App

Work from `aurelia-books/` for product development.

```powershell
cd aurelia-books
npm install
npm run dev
```

Useful scripts:

```powershell
npm run lint
npm run build
npm run android:sync
npm run android:apk
```

Android output is generated by Gradle under:

```text
aurelia-books/android/app/build/outputs/apk/debug/
```

APK/AAB files and local Android toolchains are ignored by git.

## Features

- Import and read `.epub` files offline.
- Store books, progress, bookmarks, and lists locally.
- Continue reading from the last saved position.
- Search and filter the library.
- Organize books into lists/shelves.
- Reader settings for theme, typography, reading mode, and spacing.
- Android packaging through Capacitor.

## Cleanup Rules

Do not commit:

- `node_modules/`
- `dist/`
- Android build outputs
- generated APK/AAB files
- local Android SDK/JDK folders
- test screenshots, perf screenshots, and temporary QA captures

Keep source assets such as app icons, splash images, branding files, and demo EPUBs in the app folders.
